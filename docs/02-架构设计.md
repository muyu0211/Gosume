## 2.4 数据流

### 2.4.1 编辑-预览流（核心链路）

```
用户编辑表单
    │
    ▼
React 表单组件 (EditorSection)
    │ onChange
    ▼
Zustand resumeStore (前端状态)
    │ 调用 Wails v3 Binding
    ▼
Go ResumeService.UpdateField()
    │ 更新内存中的 Resume 对象
    ▼
Go RenderEngine.RenderHTML(resume, template)
    │ html/template + Sprig
    ▼
HTML 字符串
    │ 通过 Wails v3 Binding 返回
    ▼
Zustand resumeStore.previewHtml
    │
    ▼
PreviewPanel (iframe / innerHTML)
    │
    ▼
用户实时看到渲染结果
```

### 2.4.2 导出流

```
用户点击 "导出"
    │
    ▼
ExportDialog (选择格式与选项)
    │
    ▼
Go ExportService.Export(resume, template, options) (v3 Service Binding)
    │
    ├── format=PDF ─────────────┐
    │   ├─ RenderHTML() → HTML  │
    │   └─ go-rod → PDF buffer  │
    │                           │
    ├── format=DOCX ────────────┤
    │   └─ docxr 模板填充       │
    │                           │
    └── format=PNG ─────────────┘
        ├─ RenderHTML() → HTML
        └─ go-rod 截图 → PNG buffer
    │
    ▼
app.Dialog.SaveFile() 对话框 (v3 Manager API) → 写入磁盘
    │
    ▼
app.Event.Emit("export:completed") → 通知前端
```

### 2.4.3 项目文件流

```
新建项目
    │ Resume{Template:"modern", Data:{...}}
    ▼
编辑中 → 自动保存 → ~/ResumeCraft/autosave/autosave.resume.json
    │
用户手动保存 (Ctrl+S)
    │
保存文件对话框 → 选择路径 → ~/Documents/我的简历.resume.json
    │
    ▼
下次打开应用
    │
最近文件列表 / 打开文件对话框
    │
    ▼
读取 .resume.json → 反序列化为 Resume 对象 → 恢复编辑状态
```

## 2.5 Wails 前后端通信规范（v3）

### 2.5.1 服务注册与绑定生成

Wails v3 使用**服务注册制**替代 v2 的 `Bind` 数组。Go 服务通过 `application.NewService()` 注册，然后运行 `wails3 generate bindings` 生成 TypeScript 绑定。

```go
// Go 端 (pkg/service/resume_service.go)
type ResumeService struct{}

func (s *ResumeService) GetResume() *model.Resume          { ... }
func (s *ResumeService) UpdateField(path string, value json.RawMessage) error { ... }
func (s *ResumeService) RenderPreview() (string, error)    { ... }

// 注册 (main.go)
app := application.New(application.Options{
    Services: []application.Service{
        application.NewService(&ResumeService{}),
    },
})
```

```bash
# 生成前端 TypeScript 绑定
wails3 generate bindings
# 输出: frontend/bindings/resume-craft.ts
```

```typescript
// 前端调用（由 wails3 generate bindings 生成）
import { ResumeService } from '../bindings/resume-craft'
const resume = await ResumeService.GetResume()
```

### 2.5.2 Go → 前端事件（v3 Manager API）

```go
// Go 端发送事件（通过 app.Event 管理器，不再需要 ctx）
app.Event.Emit("autosave:completed", time.Now().Unix())
app.Event.Emit("export:progress", ExportProgress{Percent: 50})
```

```typescript
// 前端监听事件（通过 app.Event 管理器）
import { app } from '../bindings/resume-craft'
app.Event.On('export:progress', (progress: ExportProgress) => { ... })
```

### 2.5.3 文件对话框（v3 Manager API）

```go
// Go 端（通过 app.Dialog 管理器）
filePath, err := app.Dialog.OpenFile(application.OpenFileDialogOptions{...})
filePath, err := app.Dialog.SaveFile(application.SaveFileDialogOptions{...})
```

### 2.5.4 JSON 类型同步

Go 的 `model.Resume` 与 TypeScript 的 `Resume` 接口必须保持字段一致。任何 Go 模型变更需要同步更新前端类型定义。运行 `wails3 generate bindings` 会自动同步服务方法签名，但数据模型的结构体类型需手动保持一致。

## 2.6 安全与权限

| 操作 | 权限需求 |
|------|----------|
| 读取/写入项目文件 | 用户选择的文件路径（文件对话框） |
| 自动保存 | 应用数据目录（`%APPDATA%/ResumeCraft/`） |
| 导出文件 | 用户选择的保存路径（保存文件对话框） |
| 网络访问 | 仅模板市场（可选功能，默认无网络请求） |
| 系统字体读取 | 只读，无安全风险 |

## 2.7 平台兼容性
