# 04 — 模板系统

## 4.1 模板概念

模板是简历的"皮肤"。一个模板是一个自包含的文件夹，包含 HTML 结构、CSS 样式、元信息和可选的 DOCX 模板。模板使用 Go 的 `html/template` 语法进行数据绑定，通过 Sprig 函数库增强表达能力。

**核心理念**：模板开发者只需关注 HTML/CSS 排版，用户数据以固定变量名注入，无需了解用户数据的具体来源。

## 4.2 模板目录规范

```
<template-name>/
├── template.json          # 模板元信息（必需）
├── template.html           # HTML 模板（必需）
├── styles.css              # 模板样式（必需）
├── preview.png             # 预览图 800×1132px（必需）
├── template.docx           # DOCX 模板（可选，用于 docxr 填充）
├── fonts/                  # 自带的字体文件（可选）
│   └── custom-font.ttf
└── assets/                 # 其他资源（可选）
    ├── background.png
    └── icons/
```

## 4.4 template.html 规范

### 4.4.1 基本结构

```html
<!DOCTYPE html>
<html lang="{{.Meta.Language}}">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{{.Personal.FullName}} - 简历</title>
    <style>
        /* 内联 CSS 变量定义 */
        {{template "styles.css" .}}
    </style>
</head>
<body class="resume-page">
    <div class="resume-container">
        <!-- 个人信息区 -->
        {{template "sections/personal" .Personal}}

        <!-- 个人总结 -->
        {{if .Summary}}
        {{template "sections/summary" .}}
        {{end}}

        <!-- 工作经历 -->
        {{if .Jobs}}
        {{template "sections/jobs" .Jobs}}
        {{end}}

        <!-- 教育背景 -->
        {{if .Education}}
        {{template "sections/education" .Education}}
        {{end}}

        <!-- 技能 -->
        {{if .Skills}}
        {{template "sections/skills" .Skills}}
        {{end}}

        <!-- 更多模块... -->
    </div>
</body>
</html>
```

### 4.4.3 可用的模板函数（Sprig + 自定义）

**Sprig 函数库（70+ 函数）**：

```go
// 字符串操作
{{.Personal.FullName | upper}}          // 大写
{{.Summary | trunc 200}}               // 截断
{{.Personal.Email | lower}}            // 小写

// 日期格式化
{{.Job.StartDate | date "2006-01" "Jan 2006"}}  // "Jun 2020"

// 列表操作

// 条件判断
{{if gt (len .Jobs) 3}}...{{end}}      // 如果工作经历超过 3 条
{{default "暂无" .Summary}}             // 设置默认值

// 字符串格式化
{{printf "%s@%s" .Name .Domain}}
```

**自定义函数**：

```go
// pkg/template/funcs.go
var CustomFuncMap = template.FuncMap{
    // 日期范围格式化
    "dateRange": func(start, end string, isCurrent bool) string {
        if isCurrent || end == "" {
            return start + " - 至今"
        }
        return start + " - " + end
    },

    // 分页控制（强制分页）
    "pageBreak": func() template.HTML {
        return template.HTML(`<div class="page-break"></div>`)
    },

    // 技能等级渲染
    "skillLevel": func(level int) template.HTML {
        var buf strings.Builder
        for i := 0; i < 5; i++ {
            if i < level {
                buf.WriteString(`<span class="skill-dot filled"></span>`)
            } else {
                buf.WriteString(`<span class="skill-dot"></span>`)
            }
        }
        return template.HTML(buf.String())
    },

    // 多语言切换
    "i18n": func(lang, zhKey, enKey string) string {
        if lang == "zh-CN" { return zhKey }
        return enKey
    },

    // 换行转 <br>
    "nl2br": func(s string) template.HTML {
        return template.HTML(strings.Replace(template.HTMLEscapeString(s), "\n", "<br>", -1))
    },

    // 安全 HTML 输出
    "safeHTML": func(s string) template.HTML {
        return template.HTML(s)
    },
}
```

## 4.5 模板数据校验

模板元信息中声明的 `data_schema` 决定该模板需要哪些数据字段。当用户切换模板时，应用会检查现有数据是否满足新模板的要求。

```go
// pkg/template/validator.go
type ValidationResult struct {
    Valid    bool
    Warnings []string   // 缺少可选字段的提示
    Errors   []string   // 缺少必需字段的错误
}

func ValidateDataForTemplate(tmpl *Template, data *model.Resume) *ValidationResult {
    result := &ValidationResult{Valid: true}

    schema := tmpl.Meta.DataSchema

    // 检查个人信息必需字段
    for _, field := range schema.Personal.Required {
        if isEmpty(data.Personal, field) {
            result.Errors = append(result.Errors,
                fmt.Sprintf("缺少必填信息: 个人信息.%s", field))
            result.Valid = false
        }
    }

    // 检查模块必需数量
    if schema.Jobs != nil && schema.Jobs.MinCount > 0 {
        if len(data.Jobs) < schema.Jobs.MinCount {
            result.Errors = append(result.Errors,
                fmt.Sprintf("至少需要 %d 条工作经历", schema.Jobs.MinCount))
            result.Valid = false
        }
    }

    return result
}
```

## 4.6 模板管理系统

### 4.6.1 模板加载器

```go
// pkg/template/loader.go
type Loader struct {
    builtin embed.FS          // 编译时内嵌的内置模板
    userDir string             // 用户模板目录
}

func (l *Loader) LoadAll() ([]*Template, error) {
    var templates []*Template

    // 1. 加载内置模板
    builtin, err := l.loadFromFS(l.builtin)
    if err != nil { return nil, err }
    templates = append(templates, builtin...)

    // 2. 加载用户模板
    userTemplates, err := l.loadFromDir(l.userDir)
    if err != nil { return nil, err }
    templates = append(templates, userTemplates...)

    return templates, nil
}
```

## 4.7 模板开发指南

### 4.7.1 快速开始

1. 复制 `templates/_boilerplate/` 目录
2. 修改 `template.json` 填写元信息
3. 编辑 `template.html` 和 `styles.css`
4. 在应用中选择此模板预览效果
5. 测试导出 PDF/DOCX/PNG
6. 打包为 zip 分发

### 4.7.2 模板开发最佳实践

1. **字体安全**：使用 `font-family` 降级链表，中文简历始终包含 `'PingFang SC', 'Microsoft YaHei'`
2. **打印优先**：CSS 使用 `mm`/`pt` 单位，避免 `px`，确保 PDF 输出与屏幕预览一致
3. **A4 尺寸**：可用区域约 180mm × 257mm（考虑 15mm 页边距）
4. **一页原则**：简历模板默认设计为单页 A4
5. **颜色可控**：使用 CSS 变量 `var(--primary-color)` 而不是硬编码颜色，便于未来支持配色切换
6. **适度使用图标**：避免依赖外部图标库，使用 CSS 绘制或内联 SVG
7. **测试空值**：模板中始终用 `{{if .Field}}...{{end}}` 判断字段是否存在
8. **DOCX 同步**：如果提供 template.docx，确保与 HTML 模板视觉效果一致

### 4.7.3 模板验证清单

- [ ] A4 纸张打印不溢出（实际测量）
- [ ] 中文字体正确显示
