# 05 — 导出系统

## 5.1 概述

导出系统负责将简历数据 + 模板渲染为最终输出文件。支持三种输出格式：PDF（主要）、DOCX（主要）、PNG（次要）。

## 5.2 导出管线总览

```
Resume Data + Template
         │
         ▼
  ┌──────────────┐
  │  HTML 渲染    │  ← html/template + Sprig
  │  (RenderHTML) │    数据 + 模板 → 完整 HTML 文档
  └──────┬───────┘
         │
         ├──────────────────┬──────────────────┐
         ▼                  ▼                  ▼
  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
  │  PDF 导出     │  │  DOCX 导出    │  │  PNG 导出     │
  │  (go-rod)    │  │  (docxr)     │  │  (go-rod)    │
  │              │  │              │  │              │
  │ HTML→Chromium│  │ 数据→DOCX模板 │  │ HTML→截图    │
  │ →PDF Buffer  │  │ →DOCX Buffer │  │ →PNG Buffer  │
  └──────────────┘  └──────────────┘  └──────────────┘
         │                  │                  │
         └──────────────────┴──────────────────┘

```

## 5.3 导出接口

```go
// pkg/export/exporter.go
package export

import "io"

// ExportFormat 导出格式
type ExportFormat string

const (
    FormatPDF  ExportFormat = "pdf"
    FormatDOCX ExportFormat = "docx"
    FormatPNG  ExportFormat = "png"
)

// ExportOptions 导出选项
type ExportOptions struct {
    Format     ExportFormat   `json:"format"`
    PaperSize  string         `json:"paper_size"`  // "A4" / "Letter"
    Scale      float64        `json:"scale"`       // PDF/PNG 缩放因子，默认 1.0
    PageRange  string         `json:"page_range"`  // "1" / "1-2" / "" 表示全部
    EmbedFonts bool           `json:"embed_fonts"` // PDF 是否嵌入字体
}

// Exporter 导出器接口
type Exporter interface {
    Export(data io.Reader, templateID string, opts ExportOptions) ([]byte, error)
    SupportedFormats() []ExportFormat
}

// ExportManager 导出管理器
type ExportManager struct {
    pdfExporter  *PDFExporter
    docxExporter *DOCXExporter
    pngExporter  *PNGExporter
    renderer     *HTMLRenderer
}

func (m *ExportManager) Export(resume *model.Resume, opts ExportOptions) ([]byte, error) {
    switch opts.Format {
    case FormatPDF:
        return m.pdfExporter.Export(resume, opts)
    case FormatDOCX:
        return m.docxExporter.Export(resume, opts)
    case FormatPNG:
        return m.pngExporter.Export(resume, opts)
    default:
        return nil, fmt.Errorf("unsupported format: %s", opts.Format)
    }
}
```

## 5.4 PDF 导出

### 5.4.1 技术方案：go-rod

使用 go-rod（无头 Chromium）将 HTML 渲染为 PDF。这是目前 Go 生态中排版还原度最高的方案。

**为什么不用 gofpdf / maroto？**
- HTML/CSS 排版能力远强于程序化 PDF 构造
- 模板开发者只需写 HTML/CSS，无需学习 PDF API
- 中文字体通过 CSS `@font-face` 即可支持，无需复杂字体注册

### 5.4.2 实现

```go
// pkg/render/pdf.go
package render

import (
    "github.com/go-rod/rod"
    "github.com/go-rod/rod/lib/proto"
)

// PDFRenderer 将 HTML 渲染为 PDF
type PDFRenderer struct {
    browser *rod.Browser
}

func NewPDFRenderer() *PDFRenderer {
    // 使用 go-rod 自带的 Chromium 或系统 Chrome
    browser := rod.New().MustConnect()
    return &PDFRenderer{browser: browser}
}

// Render 将 HTML 渲染为 PDF 字节
func (r *PDFRenderer) Render(htmlContent string, opts PDFOptions) ([]byte, error) {
    page := r.browser.MustPage()
    defer page.MustClose()

    // 设置 HTML 内容
    page.MustSetContent(htmlContent)

    // 等待所有字体加载完成
    page.MustWaitStable()

    // 如果指定了页数范围，计算实际高度
    // A4: 210mm × 297mm
    paperWidth := 8.27   // inches
    paperHeight := 11.69 // inches

    if opts.PaperSize == "Letter" {
        paperWidth = 8.5
        paperHeight = 11.0
    }

    // 生成 PDF
    pdfBytes := page.MustPDF(&proto.PagePrintToPDF{
        PaperWidth:   paperWidth,
        PaperHeight:  paperHeight,
        MarginTop:    0,
        MarginBottom: 0,
        MarginLeft:   0,
        MarginRight:  0,
        PrintBackground: true,      // 打印背景色
        PreferCSSPageSize: true,    // 优先使用 CSS @page 规则
        Scale:        opts.Scale,
        PageRanges:   opts.PageRange,
        DisplayHeaderFooter: false,
    })

    return pdfBytes, nil
}

type PDFOptions struct {
    PaperSize string  // "A4" / "Letter"
    Scale     float64 // 默认 1.0
    PageRange string  // "1" / "1-2"
}

func (r *PDFRenderer) Close() {
    r.browser.Close()
}
```

### 5.4.3 PDF 质量控制

| 检查项 | 标准 |
|--------|------|
| 纸张尺寸 | A4 210mm × 297mm (±1mm) |
| 页边距 | 由 CSS `@page` 控制，默认 15mm |
| 字体嵌入 | 默认由 Chromium 处理 |
| 超链接 | 保留（PDF 内跳转和外部链接） |
| DPI | 96 DPI（屏幕精度），文本足够清晰 |
| 文件大小 | 单页 < 500KB（无图片时） |

## 5.5 DOCX 导出

### 5.5.1 技术方案：docxr 模板填充

**为什么用模板填充而非程序化生成？**
- DOCX 排版复杂，代码逐元素生成工作量大且效果难以保证
- 模板填充：设计师在 Word 中排好版面，程序仅替换变量
- 每套 HTML 模板配套提供对应的 DOCX 模板

### 5.5.2 DOCX 模板语法

docxr 使用 Go `text/template` 语法填充 `.docx` 文件中的占位符。

**步骤**：
1. 在 Word 中设计简历模板并保存为 `template.docx`
2. 在需要填充的位置插入 `{{.Personal.FullName}}` 等占位符
3. 将 `template.docx` 放入模板文件夹

**DOCX 模板示例（文本内容）**：

```
[页眉]
姓名: {{.Personal.FullName}}
邮箱: {{.Personal.Email}} | 电话: {{.Personal.Phone}}

[正文]
{{.Summary}}

工作经历:
{{range .Jobs}}
{{.Company}} | {{.Title}} | {{dateRange .StartDate .EndDate .IsCurrent}}
{{range .Highlights}}
• {{.}}
{{end}}
{{end}}
```

### 5.5.3 实现

```go
// pkg/render/docx.go
package render

import (
    "github.com/otfot/docxr"
)

// DOCXRenderer 基于 docxr 的 DOCX 生成器
type DOCXRenderer struct {
    templatePath string  // DOCX 模板文件路径
}

func NewDOCXRenderer(templateDir string) *DOCXRenderer {
    return &DOCXRenderer{
        templatePath: filepath.Join(templateDir, "template.docx"),
    }
}

// Render 将数据填充到 DOCX 模板
func (r *DOCXRenderer) Render(resume *model.Resume) ([]byte, error) {
    // 方案 A：docxr 模板填充
    outFile := filepath.Join(os.TempDir(), "output.docx")
    err := docxr.Render(r.templatePath, outFile, resume)
    if err != nil {
        return nil, fmt.Errorf("docx render: %w", err)
    }

    return os.ReadFile(outFile)
}
```

### 5.5.4 DOCX 模式讨论

对于没有提供 `template.docx` 的模板，应用有两种处理方式：

**方案 A（推荐）**：提示用户"此模板暂不支持 DOCX 导出"，并建议使用 PDF 格式

**方案 B（长期）**：实现 HTML→DOCX 转换器（基于 `go-docx` 或 `pandoc` 外部调用）

```go
// 方案 B: pandoc 转换（如果系统安装了 pandoc）
func HTMLToDOCX(htmlContent string) ([]byte, error) {
    cmd := exec.Command("pandoc",
        "-f", "html",
        "-t", "docx",
        "--output", "-",
        "--from=html",
    )
    cmd.Stdin = strings.NewReader(htmlContent)
    return cmd.Output()
}
```

MVP 阶段采用方案 A，后续再评估方案 B 的可行性。

## 5.6 PNG 导出

### 5.6.1 技术方案：go-rod 截图

复用 PDF 渲染管线，将同一份 HTML 渲染结果截图为 PNG。

```go
// pkg/render/png.go
package render

import (
    "github.com/go-rod/rod"
    "github.com/go-rod/rod/lib/proto"
)

// PNGRenderer 将 HTML 渲染为 PNG
type PNGRenderer struct {
    browser *rod.Browser
}

func NewPNGRenderer(browser *rod.Browser) *PNGRenderer {
    return &PNGRenderer{browser: browser}
}

// Render 将 HTML 截图渲染为 PNG 字节
// 选择 Render 而非 RenderPages，MVP 阶段仅截取首页
func (r *PNGRenderer) Render(htmlContent string, scale float64) ([]byte, error) {
    page := r.browser.MustPage()
    defer page.MustClose()

    page.MustSetContent(htmlContent)
    page.MustWaitStable()

    // A4 尺寸 @ 2x 缩放保证清晰度
    width := 794 * scale   // 210mm → 794px @ 96dpi
    height := 1123 * scale // 297mm → 1123px @ 96dpi

    page.MustSetViewport(int(width), int(height), 2.0, false)

    // 截取整个页面
    screenshot := page.MustScreenshot(proto.PageCaptureScreenshot{
        Format:  "png",
        Quality: 100,
        Clip: &proto.PageViewport{
            X: 0, Y: 0,
            Width:  float64(width),
            Height: float64(height),
            Scale:  2.0,
        },
    })

    return screenshot, nil
}
```

### 5.6.2 PNG 规格

| 参数 | 值 |
|------|-----|
| 尺寸 | A4 794×1123px（@1×）/ 1588×2246px（@2×） |
| DPI | 96 @1× / 192 @2×（足够清晰） |
| 格式 | PNG, RGBA |
| 文件大小 | 约 200-800KB（@2×） |
| 背景 | 白色（由模板 CSS 的 `background` 提供） |

## 5.7 导出服务接口（Wails v3 绑定）

```go
// pkg/service/export_service.go
package service

import (
    "fmt"
    "os"

    "resume-craft/pkg/export"
    "resume-craft/pkg/model"

    "github.com/wailsapp/wails/v3/pkg/application"
)

type ExportService struct {
    wailsApp      *application.App     // v3: 通过 Manager API 调用运行时功能
    manager       *export.ExportManager
    resumeService *ResumeService
}

// Inject 依赖注入（在 app.go 中调用）
func (s *ExportService) Inject(app *application.App, manager *export.ExportManager, resumeSvc *ResumeService) {
    s.wailsApp = app
    s.manager = manager
    s.resumeService = resumeSvc
}

// Export 执行导出，打开保存文件对话框让用户选择位置
func (s *ExportService) Export(opts export.ExportOptions) error {
    // 1. 获取当前简历数据
    resume := s.resumeService.GetResume()

    // 2. 渲染并导出
    data, err := s.manager.Export(resume, opts)
    if err != nil {
        return err
    }

    // 3. 打开保存文件对话框（v3: app.Dialog 管理器）
    defaultName := fmt.Sprintf("%s_简历.%s",
        resume.Personal.FullName,
        formatSuffix(opts.Format))

    filePath, err := s.wailsApp.Dialog.SaveFile(application.SaveFileDialogOptions{
        Title:           "导出简历",
        DefaultFilename: defaultName,
        Filters: []application.FileFilter{
            {DisplayName: getFilterName(opts.Format), Pattern: getFilterPattern(opts.Format)},
        },
    })
    if err != nil {
        return err
    }
    if filePath == "" {
        return nil // 用户取消
    }

    // 4. 写入磁盘
    if err := os.WriteFile(filePath, data, 0644); err != nil {
        return err
    }

    // 5. 更新导出计数
    resume.Meta.ExportCount++
    s.resumeService.SetResume(resume)

    // 6. 通知前端完成（v3: app.Event 管理器）
    s.wailsApp.Event.Emit("export:completed", filePath)

    return nil
}
```

## 5.8 导出进度反馈

对于大型简历（多页），导出过程可能需要 2-5 秒，前端应展示进度。

```typescript
// frontend/src/hooks/useExport.ts
import { ExportService } from '../bindings/resume-craft'
import { app } from '../bindings/resume-craft'

export function useExport() {
    const [isExporting, setIsExporting] = useState(false)
    const [progress, setProgress] = useState(0)

    const doExport = async (format: string) => {
        setIsExporting(true)
        setProgress(0)

        // v3: 通过 app.Event.On() 监听事件
        const cancelFn = app.Event.On('export:progress', (p: number) => setProgress(p))

        try {
            await ExportService.Export({ format })
        } finally {
        } finally {
            setIsExporting(false)
        }
    }

    return { isExporting, progress, doExport }
}
```
