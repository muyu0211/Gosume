## 7.2 Wails v3 核心概念

### 7.2.1 v2 → v3 关键变化

| 方面 | Wails v2 | Wails v3 |
|------|----------|----------|
| 入口函数 | `wails.Run(&options.App{...})` | `app := application.New(...); app.Run()` |
| 导入路径 | `github.com/wailsapp/wails/v2` | `github.com/wailsapp/wails/v3/pkg/application` |
| 绑定注册 | `Bind: []interface{}{...}` | `Services: []application.Service{application.NewService(&Svc{})}` |
| 前端绑定路径 | `wailsjs/go/...` | `frontend/bindings/...`（通过 `wails3 generate bindings` 生成） |
| 窗口创建 | `options.App{Title, Width, Height...}` | `app.Window.NewWithOptions(application.WebviewWindowOptions{...})` |
| 静态资源 | `AssetServer: &assetserver.Options{Assets: assets}` | `Assets: application.AssetOptions{Handler: application.AssetFileServerFS(assets)}` |
| 单实例锁 | `SingleInstanceLock: &options.SingleInstanceLock{...}` | `SingleInstance: &application.SingleInstanceOptions{...}` |
| 运行时事件 | `runtime.EventsEmit(ctx, name, data)` | `app.Event.Emit(name, data)` |
| 文件对话框 | `runtime.OpenFileDialog(ctx, opts)` | `app.Dialog.OpenFile(opts)` |
| 浏览器打开 | `runtime.BrowserOpenURL(ctx, url)` | `app.Browser.OpenURL(url)` |
| 日志 | `runtime.LogInfo(ctx, msg)` | `app.Log.Info(msg)` |
| 启动/关闭 | `OnStartup(ctx)` / `OnShutdown(ctx)` | 服务实现 `ServiceStartup(ctx, opts)` / `ServiceShutdown()` |
| 上下文传递 | 每个方法调用携带 `ctx context.Context` | 不再需要透传 ctx，服务在 `ServiceStartup` 获取并保存 |
| 配置文件 | `wails.json` | `wails.json`（格式有调整，schema v3） |
| 绑定生成 | `wails dev` 时自动生成 | `wails3 generate bindings` 手动/自动生成 |

### 7.2.2 架构变化说明

Wails v3 引入了 **Manager 模式**，将所有运行时能力拆分为独立管理器，挂载在 `*application.App` 上：

```
app.Event      → 事件系统（Emit / On）
app.Dialog     → 文件对话框（OpenFile / SaveFile / Message）
app.Window     → 窗口管理（New / NewWithOptions）
app.Browser    → 浏览器操作（OpenURL）
app.Log        → 日志系统（Info / Warning / Error / Debug）
app.Clipboard  → 剪贴板
app.SystemTray → 系统托盘
app.KeyBinding → 键盘快捷键
app.Env        → 环境信息
```

服务层不再需要通过 `ctx context.Context` 透传运行时能力，改为持有 `*application.App` 引用，通过管理器 API 调用。

## 7.3 Wails 应用引导

### 7.3.1 入口文件

```go
// main.go
package main

import (
    "log"

    "github.com/wailsapp/wails/v3/pkg/application"
)

//go:embed all:frontend/dist
var assets embed.FS

//go:embed templates
var builtinTemplates embed.FS

func main() {
    // 创建应用实例并初始化核心组件
    appCore := NewApp()

    // 创建 Wails 应用
    app := application.New(application.Options{
        Name:        "Resume Craft",
        Description: "桌面级简历制作工具",
        Icon:        assets, // 应用图标

        // 服务注册（替代 v2 的 Bind）
        Services: []application.Service{
            application.NewService(appCore.ResumeService),
            application.NewService(appCore.TemplateService),
            application.NewService(appCore.ExportService),
            application.NewService(appCore.FileService),
            application.NewService(appCore.SystemService),
        },

        // 静态资源
        Assets: application.AssetOptions{
            Handler: application.AssetFileServerFS(assets),
        },

        // 单实例锁
        SingleInstance: &application.SingleInstanceOptions{
            UniqueID: "resume-craft-app-v1",
            OnSecondInstance: func(data application.SecondInstanceData) {
                // 第二个实例启动时，激活已有窗口
                appCore.onSecondInstance(data)
            },
        },

        // macOS 特定配置
        Mac: application.MacOptions{
            ApplicationShouldTerminateAfterLastWindowClosed: false,
        },
    })

    // 创建主窗口
    appCore.mainWindow = app.Window.NewWithOptions(application.WebviewWindowOptions{
        Title:    "Resume Craft",
        Width:    1280,
        Height:   800,
        MinWidth: 960,
        MinHeight: 600,
        URL:      "/",
        // 启动时最大化
        StartState: application.WindowStartStateMaximised,
        // 启用右键菜单
        EnableDefaultContextMenu: true,
    })

    // 将 app 引用注入到服务中
    appCore.injectApp(app)

    // 运行应用（阻塞直到退出）
    err := app.Run()
    if err != nil {
        log.Fatal(err)
    }
}
```

### 7.3.2 应用生命周期

```go
// app.go
package main

import (
    "context"
    "os"
    "path/filepath"
    "sync"

    "resume-craft/pkg/service"
    "resume-craft/pkg/store"
    "resume-craft/pkg/template"
    "resume-craft/pkg/render"
    "resume-craft/pkg/export"

    "github.com/wailsapp/wails/v3/pkg/application"
)

type App struct {
    // Wails 应用引用（访问管理器 API）
    wailsApp    *application.App

    // 主窗口引用
    mainWindow  *application.WebviewWindow

    // 服务层
    ResumeService   *service.ResumeService
    TemplateService *service.TemplateService
    ExportService   *service.ExportService
    FileService     *service.FileService
    SystemService   *service.SystemService

    // 核心组件
    templateLoader  *template.Loader
    htmlRenderer    *render.HTMLRenderer
    pdfRenderer     *render.PDFRenderer
    exportManager   *export.ExportManager

    // 项目存储
    projectStore    *store.ProjectStore

    mu sync.Mutex
}

func NewApp() *App {
    return &App{}
}

// injectApp 向所有服务注入 Wails App 引用和核心依赖
func (a *App) injectApp(app *application.App) {
    a.wailsApp = app

    // 1. 初始化数据目录
    dataDir := a.getDataDir()
    os.MkdirAll(dataDir, 0755)
    os.MkdirAll(filepath.Join(dataDir, "autosave"), 0755)
    os.MkdirAll(filepath.Join(dataDir, "templates"), 0755)

    // 2. 初始化模板加载器
    a.templateLoader = template.NewLoader(builtinTemplates, filepath.Join(dataDir, "templates"))

    // 3. 初始化渲染器
    a.htmlRenderer = render.NewHTMLRenderer(a.templateLoader)
    a.pdfRenderer = render.NewPDFRenderer()

    // 4. 初始化导出管理器
    docxRenderer := render.NewDOCXRenderer(a.templateLoader)
    pngRenderer := render.NewPNGRenderer(a.pdfRenderer.Browser())
    a.exportManager = export.NewExportManager(a.pdfRenderer, docxRenderer, pngRenderer, a.htmlRenderer)

    // 5. 初始化存储层
    a.projectStore = store.NewProjectStore(dataDir)

    // 6. 向各服务注入依赖
    a.ResumeService.Inject(a.projectStore, a.htmlRenderer)
    a.TemplateService.Inject(a.templateLoader)
    a.ExportService.Inject(app, a.exportManager, a.ResumeService)
    a.FileService.Inject(app, a.projectStore, a.ResumeService)
    a.SystemService.Inject(app, dataDir)

    // 7. 检查并恢复自动保存
    if resume, err := a.projectStore.LoadAutoSave(); err == nil && resume != nil {
        app.Event.Emit("autosave:found", resume.Meta.UpdatedAt)
    }
}

// ServiceStartup 在所有服务启动后调用（由各服务的 ServiceStartup 触发）
func (a *App) ServiceStartup(ctx context.Context, opts application.ServiceOptions) error {
    // 全局初始化逻辑
    app.Log.Info("Resume Craft started")
    return nil
}

// ServiceShutdown 应用关闭前调用
func (a *App) ServiceShutdown() {
    if a.ResumeService != nil {
        a.ResumeService.AutoSave()
    }
    if a.pdfRenderer != nil {
        a.pdfRenderer.Close()
    }
    app.Log.Info("Resume Craft shutdown complete")
}

func (a *App) getDataDir() string {
    configDir, err := os.UserConfigDir()
    if err != nil {
        configDir = filepath.Join(os.Getenv("HOME"), ".config")
    }
    return filepath.Join(configDir, "ResumeCraft")
}

func (a *App) onSecondInstance(data application.SecondInstanceData) {
    // 第二个实例启动时，激活已有窗口
    a.mainWindow.Show()
    a.mainWindow.Focus()
}
```

## 7.4 服务层设计

### 7.4.1 设计原则

Wails v3 中服务通过 `application.NewService()` 注册。服务结构体可实现以下生命周期方法：

| 方法 | 说明 |
|------|------|
| `ServiceName() string` | 返回服务名（用于日志标识） |
| `ServiceStartup(ctx context.Context, opts application.ServiceOptions) error` | 应用启动时调用，接收长期 ctx |
| `ServiceShutdown() error` | 应用关闭时调用 |

服务通过 `Inject()` 方法接收应用引用和核心依赖（构造函数注入模式）。

func (s *ResumeService) NewResume(templateID string, language string) (*model.Resume, error) {
    now := time.Now()
    resume := &model.Resume{
        Version: "1.0",
        Meta: model.ResumeMeta{
            TemplateID: templateID,
            Language:   language,
            FontSize:   10,
            PageMargin: "normal",
            CreatedAt:  now,
            UpdatedAt:  now,
        },
        Personal: model.Personal{},
    }

    s.mu.Lock()
    s.current = resume
    s.mu.Unlock()

    return resume, nil
}

// GetResume 获取当前简历数据（供前端获取完整状态）
func (s *ResumeService) GetResume() *model.Resume {
    s.mu.RLock()
    defer s.mu.RUnlock()
    return s.current
}

// SetResume 设置当前简历数据（打开项目时使用）
func (s *ResumeService) SetResume(resume *model.Resume) {
    s.mu.Lock()
    defer s.mu.Unlock()
    s.current = resume

// UpdateField 更新简历中的某个字段
// path 使用点号分隔： "personal.full_name", "jobs[0].company"
// value 是 JSON 格式的任意值

    s.mu.Lock()
    defer s.mu.Unlock()

        return fmt.Errorf("no resume loaded")
    }

    if err := model.SetFieldByPath(s.current, path, value); err != nil {
        return fmt.Errorf("update field %s: %w", path, err)
    }

    s.current.Meta.UpdatedAt = time.Now()
    return nil
}

// TemplateService 模板管理服务
type TemplateService struct {
    ctx    context.Context
    loader *template.Loader
    cache  map[string]*template.Template
    mu     sync.RWMutex
}

func (s *TemplateService) ServiceName() string { return "TemplateService" }

func (s *TemplateService) ServiceStartup(ctx context.Context, opts application.ServiceOptions) error {
    s.ctx = ctx
    return nil
}

func (s *TemplateService) Inject(loader *template.Loader) {
    s.loader = loader
}

// ListTemplates 获取所有可用模板的元信息
func (s *TemplateService) ListTemplates() ([]*template.TemplateMeta, error) {
    templates, err := s.loader.LoadAll()
    if err != nil {
        return nil, err
    }

    var metas []*template.TemplateMeta
    for _, t := range templates {
        metas = append(metas, &t.Meta)
    }
    return metas, nil
}

// GetTemplate 获取单个模板的元信息
func (s *TemplateService) GetTemplate(id string) (*template.TemplateMeta, error) {
    t, err := s.loader.LoadByID(id)
    if err != nil {
        return nil, err
    }
    return &t.Meta, nil
}

// ImportTemplate 导入用户模板
func (s *TemplateService) ImportTemplate(sourcePath string) (*template.TemplateMeta, error) {
    if err := s.loader.InstallTemplate(sourcePath); err != nil {
        return nil, fmt.Errorf("import template: %w", err)
    }

    t, _ := s.loader.LoadByPath(sourcePath)
    return &t.Meta, nil
}

// DeleteTemplate 删除用户模板（内置模板不可删除）
func (s *TemplateService) DeleteTemplate(id string) error {
    t, err := s.loader.LoadByID(id)
    if err != nil {
        return err
    }

    if t.IsBuiltin {
        return fmt.Errorf("cannot delete builtin template: %s", id)
    }

    return s.loader.DeleteTemplate(id)
}

// ValidateForTemplate 检查当前数据是否满足模板要求
func (s *TemplateService) ValidateForTemplate(templateID string, resume *model.Resume) *template.ValidationResult {
    t, err := s.loader.LoadByID(templateID)
    if err != nil {
        return &template.ValidationResult{
            Valid:  false,
            Errors: []string{fmt.Sprintf("模板不存在: %s", templateID)},
        }
    }
    return template.ValidateDataForTemplate(t, resume)
}

// pkg/service/export_service.go
package service

import (
    "fmt"
    "os"
    "time"

    "resume-craft/pkg/model"
    "resume-craft/pkg/export"

    "github.com/wailsapp/wails/v3/pkg/application"
)

// ExportService 导出服务
type ExportService struct {
    wailsApp       *application.App
    exportManager  *export.ExportManager
    resumeService  *ResumeService
}

func (s *ExportService) ServiceName() string { return "ExportService" }

func (s *ExportService) Inject(app *application.App, manager *export.ExportManager, resumeSvc *ResumeService) {
    s.wailsApp = app
    s.exportManager = manager
    s.resumeService = resumeSvc
}

// Export 执行导出
// 由前端调用，完成整个导出流程（渲染 + 保存文件对话框 + 写入磁盘）
func (s *ExportService) Export(opts export.ExportOptions) error {
    resume := s.resumeService.GetResume()
    if resume == nil {
        return fmt.Errorf("no resume to export")
    }

    // 更新导出计数
    resume.Meta.ExportCount++
    resume.Meta.UpdatedAt = time.Now()

    // 发送进度事件（v3：通过 app.Event 管理器）
    s.wailsApp.Event.Emit("export:progress", 10)

    // 执行导出（生成文件字节）
    data, err := s.exportManager.Export(resume, opts)
    if err != nil {
        return fmt.Errorf("export: %w", err)
    }

    s.wailsApp.Event.Emit("export:progress", 70)

    // 打开保存文件对话框（v3：通过 app.Dialog 管理器）
    defaultName := fmt.Sprintf("%s_简历.%s",
        resume.Personal.FullName,
        formatSuffix(opts.Format))

    filePath, err := s.wailsApp.Dialog.SaveFile(application.SaveFileDialogOptions{
        Title:           "保存简历",
        DefaultFilename: defaultName,
        Filters: []application.FileFilter{
            {DisplayName: getFilterName(opts.Format), Pattern: getFilterPattern(opts.Format)},
        },
    })
    if err != nil || filePath == "" {
        return err // 用户取消
    }

    // 写入文件
    if err := os.WriteFile(filePath, data, 0644); err != nil {
        return fmt.Errorf("write file: %w", err)
    }

    s.wailsApp.Event.Emit("export:progress", 100)
    s.wailsApp.Event.Emit("export:completed", filePath)

    return nil
}

func getFilterName(f export.ExportFormat) string {
    switch f {
    case export.FormatPDF:  return "PDF 文件 (*.pdf)"
    case export.FormatDOCX: return "Word 文档 (*.docx)"
    case export.FormatPNG:  return "PNG 图片 (*.png)"
    default:                return "所有文件 (*.*)"
    }
}

func getFilterPattern(f export.ExportFormat) string {
    switch f {
    case export.FormatPDF:  return "*.pdf"
    case export.FormatDOCX: return "*.docx"
    case export.FormatPNG:  return "*.png"
    default:                return "*.*"
    }
}

func formatSuffix(f export.ExportFormat) string {
    switch f {
    case export.FormatPDF:  return "pdf"
    case export.FormatDOCX: return "docx"
    case export.FormatPNG:  return "png"
    default:                return ""
    }
}

// OpenProject 打开已有项目文件
func (s *FileService) OpenProject() (*model.Resume, error) {
    filePath, err := s.wailsApp.Dialog.OpenFile(application.OpenFileDialogOptions{
        Title: "打开简历项目",
        Filters: []application.FileFilter{
            {DisplayName: "简历项目文件 (*.resume.json)", Pattern: "*.resume.json"},
            {DisplayName: "所有文件 (*.*)", Pattern: "*.*"},
        },
    })
    if err != nil || filePath == "" {
        return nil, err
    }

    resume, err := s.store.Load(filePath)
    if err != nil {
        return nil, fmt.Errorf("open project: %w", err)
    }

    // 更新当前简历数据
    s.resumeService.SetResume(resume)

    return resume, nil
}

// SaveProject 保存项目
func (s *FileService) SaveProject(filePath string) error {
    if filePath == "" {
        var err error
        filePath, err = s.wailsApp.Dialog.SaveFile(application.SaveFileDialogOptions{
            Title:           "保存简历项目",
            DefaultFilename: "我的简历.resume.json",
            Filters: []application.FileFilter{
                {DisplayName: "简历项目文件 (*.resume.json)", Pattern: "*.resume.json"},
            },
        })
        if err != nil || filePath == "" {
            return err
        }
    }

    return s.store.Save(filePath, s.resumeService.GetResume())
}

// GetRecentFiles 获取最近文件列表
func (s *FileService) GetRecentFiles() ([]store.RecentFile, error) {
    return s.store.GetRecentFiles()

    case "windows":
        return exec.Command("explorer", "/select,", path).Start()

    }

    if err != nil {

    }

    s.addRecentFile(filePath, resume)
    return resume, nil
}

// Save 写入 .resume.json 文件（原子写入）
func (s *ProjectStore) Save(filePath string, resume *model.Resume) error {
    resume.Meta.UpdatedAt = time.Now()

    data, err := json.MarshalIndent(resume, "", "  ")
    if err != nil {
        return fmt.Errorf("marshal: %w", err)
    }

    tmpPath := filePath + ".tmp"
    if err := os.WriteFile(tmpPath, data, 0644); err != nil {
        return err
    }
    if err := os.Rename(tmpPath, filePath); err != nil {
        return err
    }

    s.addRecentFile(filePath, resume)
    return nil
}

## 7.6 错误处理规范

与 v2 版本一致，无变化。

```go
// pkg/errors/errors.go
package errors

import "fmt"

type ErrorCode string

const (
    ErrTemplateNotFound   ErrorCode = "TEMPLATE_NOT_FOUND"
    ErrTemplateInvalid    ErrorCode = "TEMPLATE_INVALID"
    ErrTemplateImport     ErrorCode = "TEMPLATE_IMPORT_FAILED"
    ErrExportFailed       ErrorCode = "EXPORT_FAILED"
    ErrFileNotFound       ErrorCode = "FILE_NOT_FOUND"
    ErrFileRead           ErrorCode = "FILE_READ_FAILED"
    ErrFileWrite          ErrorCode = "FILE_WRITE_FAILED"
    ErrDataValidation     ErrorCode = "DATA_VALIDATION"
    ErrResumeNotLoaded    ErrorCode = "RESUME_NOT_LOADED"
    ErrUnsupportedFormat  ErrorCode = "UNSUPPORTED_FORMAT"
)

type AppError struct {
    Code    ErrorCode `json:"code"`
    Message string    `json:"message"`
    Detail  string    `json:"detail,omitempty"`
    Cause   error     `json:"-"`
}

func (e *AppError) Error() string { return fmt.Sprintf("[%s] %s", e.Code, e.Message) }
func (e *AppError) Unwrap() error { return e.Cause }

func New(code ErrorCode, message string) *AppError {
    return &AppError{Code: code, Message: message}
}

func Wrap(code ErrorCode, message string, cause error) *AppError {
    return &AppError{Code: code, Message: message, Cause: cause}
}
```

> **v3 注意**：Wails v3 绑定的 Go 方法返回 `error` 时，前端现在接收的是 **Error 对象**而非字符串（v2 返回字符串），可以通过 `err.code` / `err.message` 区分错误类型。

## 7.7 绑定生成

在 Wails v3 中，前端 TypeScript 绑定不再自动生成，需要通过 CLI 手动生成：

```bash
# 生成前端绑定文件到 frontend/bindings/
wails3 generate bindings

# 在 wails dev 模式下也会自动生成
```

这将在 `frontend/bindings/` 目录生成包含所有服务方法签名的 TypeScript 绑定文件，前端通过以下方式导入：

```typescript
import { ResumeService } from '../bindings/resume-craft'  // 以应用名为包名
const resume = await ResumeService.GetResume()
```
