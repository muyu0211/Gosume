# 03 — 数据模型

## 3.1 概述

简历数据以 JSON 格式存储，是用户填写的所有信息的结构化表示。数据模型与模板完全解耦，同一个数据可用于任意模板渲染。

## 3.2 顶级结构：Resume

```go
// pkg/model/resume.go
package model

import "time"

// Resume 简历顶级结构
type Resume struct {
    Version   string      `json:"version"`            // 数据格式版本，当前 "1.0"
    Meta      ResumeMeta  `json:"meta"`               // 简历元信息
    Personal  Personal    `json:"personal"`            // 个人信息
    Summary   string      `json:"summary,omitempty"`   // 个人总结/求职意向
    Jobs      []Job       `json:"jobs,omitempty"`      // 工作经历
    Projects  []Project   `json:"projects,omitempty"`  // 项目经历
    Education []Education `json:"education,omitempty"` // 教育背景
    Skills    []SkillGroup `json:"skills,omitempty"`   // 技能
    Languages []Language  `json:"languages,omitempty"` // 语言能力
    Awards    []Award     `json:"awards,omitempty"`    // 奖项荣誉
    Custom    []CustomSection `json:"custom,omitempty"`// 自定义模块
}

// ResumeMeta 简历元信息
type ResumeMeta struct {
    TemplateID  string    `json:"template_id"`   // 使用的模板 ID
    Language    string    `json:"language"`       // 简历语言 "zh-CN" / "en-US"
    FontSize    int       `json:"font_size"`      // 基准字号 pt，默认 10
    PageMargin  string    `json:"page_margin"`    // 页边距 "normal" / "narrow" / "wide"
    CreatedAt   time.Time `json:"created_at"`     // 创建时间
    UpdatedAt   time.Time `json:"updated_at"`     // 最后修改时间
    ExportCount int       `json:"export_count"`   // 导出次数
}
```

## 3.3 个人信息

```go
// Personal 个人信息
type Personal struct {
    FullName    string `json:"full_name"`              // 姓名
    EnglishName string `json:"english_name,omitempty"` // 英文名
    Email       string `json:"email,omitempty"`        // 电子邮箱
    Phone       string `json:"phone,omitempty"`        // 手机号
    Wechat      string `json:"wechat,omitempty"`       // 微信号
    QQ          string `json:"qq,omitempty"`           // QQ 号
    Location    string `json:"location,omitempty"`     // 所在城市
    Website     string `json:"website,omitempty"`      // 个人网站/博客
    LinkedIn    string `json:"linkedin,omitempty"`     // LinkedIn URL
    GitHub      string `json:"github,omitempty"`       // GitHub URL
    Avatar      string `json:"avatar,omitempty"`       // 头像 base64 (建议 ≤ 100KB)
    Birthday    string `json:"birthday,omitempty"`     // 出生日期 "1990-01"
    Gender      string `json:"gender,omitempty"`       // 性别 "male"/"female"/"other"
    JobTitle    string `json:"job_title,omitempty"`    // 当前职位/期望职位
    YearsOfExp  int    `json:"years_of_exp,omitempty"` // 工作年限
}
```

**JSON 示例**：

```json
{
    "personal": {
        "full_name": "张三",
        "email": "zhangsan@example.com",
        "phone": "138-0000-0000",
        "location": "北京",

        "github": "https://github.com/zhangsan",
        "job_title": "高级前端工程师",
        "years_of_exp": 5
    }
}
```

## 3.4 工作经历

```go
// Job 工作经历
type Job struct {
    ID          string   `json:"id"`                    // 唯一标识 UUID
    Company     string   `json:"company"`               // 公司名称
    CompanyURL  string   `json:"company_url,omitempty"` // 公司网址
    Title       string   `json:"title"`                 // 职位
    Location    string   `json:"location,omitempty"`    // 工作地点
    StartDate   string   `json:"start_date"`            // 开始日期 "2020-06"
    EndDate     string   `json:"end_date,omitempty"`    // 结束日期 "2023-08" / "" 表示至今
    IsCurrent   bool     `json:"is_current"`            // 是否当前在职
    Summary     string   `json:"summary,omitempty"`     // 工作概述（1-2 句）
    Highlights  []string `json:"highlights,omitempty"`  // 工作亮点/成就（每条 1-2 行）
    Keywords    []string `json:"keywords,omitempty"`    // 技术关键词（用于模板高亮）
}
```


## 3.7 技能

```go
// SkillGroup 技能分组（用于模板分组展示）
type SkillGroup struct {
    ID       string  `json:"id"`                // UUID
    Category string  `json:"category"`          // 分类名 "前端" / "后端" / "工具"
    Items    []Skill `json:"items"`             // 技能列表
}

// Skill 单项技能
type Skill struct {
    Name   string `json:"name"`             // 技能名 "React"
    Level  int    `json:"level,omitempty"`  // 熟练度 1-5（0 表示不显示等级）
    Icon   string `json:"icon,omitempty"`   // 图标 URL/base64（可选，由模板决定是否展示）
}
```

**JSON 示例**：

```json
{
    "skills": [
        {
            "id": "sk1",
            "category": "前端技术",
            "items": [
                { "name": "React", "level": 5 },
                { "name": "TypeScript", "level": 4 },
                { "name": "Vue.js", "level": 3 }
            ]
        },
        {
            "id": "sk2",
            "category": "工具与平台",
            "items": [
                { "name": "Git", "level": 5 },
                { "name": "Docker", "level": 3 }
            ]
        }
    ]
}
```

## 3.12 项目文件格式

项目文件扩展名为 `.resume.json`，内容为一个完整的 `Resume` 对象的 JSON 表示。

**文件大小预估**：
- 不含头像：约 2-10 KB
- 含头像（base64）：约 50-150 KB

**存储目录规范**：

```
Windows:  %APPDATA%/ResumeCraft/
macOS:    ~/Library/Application Support/ResumeCraft/
Linux:    ~/.config/ResumeCraft/

├── autosave/
│   └── autosave.resume.json        # 自动保存文件
├── recent.json                      # 最近文件列表
├── logs/                            # 日志
└── templates/                       # 用户安装的模板
    └── <template-name>/
        └── ...
```

## 3.13 数据版本兼容策略

| 场景 | 处理方式 |
|------|----------|
| 旧版本数据用新版本应用打开 | 读取时自动迁移（`version` 字段判断），`Meta.UpdatedAt` 更新 |
| 新版本数据用旧版本应用打开 | 提示用户升级应用，拒绝加载 |
| 字段删除 | 旧数据中的废弃字段在反序列化时忽略（`json:"xxx,omitempty"`） |
| 字段新增 | 新字段必须有零值默认行为，旧数据加载时自动补充默认值 |

迁移函数示例：

```go
func Migrate(rawJSON []byte) (*Resume, error) {
    var versionInfo struct {
        Version string `json:"version"`
    }
    json.Unmarshal(rawJSON, &versionInfo)

    switch versionInfo.Version {
    case "1.0":
        // 当前版本，直接反序列化
        var r Resume
        err := json.Unmarshal(rawJSON, &r)
        return &r, err
    case "":
        // 无版本号（最早期的数据），执行迁移
        // ...
    default:
        return nil, fmt.Errorf("unsupported data version: %s", versionInfo.Version)
    }
}
```

## 3.14 TypeScript 类型定义（前端需要同步）

```typescript
// frontend/src/types/resume.ts

export interface Resume {
    version: string
    meta: ResumeMeta
    personal: Personal
    summary?: string
    jobs?: Job[]
    projects?: Project[]
    education?: Education[]
    skills?: SkillGroup[]
    languages?: Language[]
    awards?: Award[]
    custom?: CustomSection[]
}

export interface Personal {
    full_name: string
    english_name?: string
    email?: string
    phone?: string
    wechat?: string
    qq?: string
    location?: string
    website?: string
    linkedin?: string
    github?: string
    avatar?: string
    birthday?: string
    gender?: 'male' | 'female' | 'other'
    job_title?: string
    years_of_exp?: number
}

// ... 其余类型定义与 Go 模型一一对应
// 使用 TypeScript 的 type/interface 与 Go 的 struct 保持字段一致
```

> **规范**：Go 模型是唯一真源（Source of Truth），TypeScript 类型定义必须与 Go 模型保持同步。在 PR review 中，Go 模型变更必须伴随前端类型更新。
