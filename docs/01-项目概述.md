# 01 — 项目概述

## 1.1 项目名称

**Resume Craft** — 桌面级简历制作工具

## 1.2 项目定位

一款**内容与排版分离**的桌面简历制作应用。用户只需以结构化表单的方式填写个人经历、技能、教育背景等信息，选择心仪的模板，程序自动完成排版、字体、配色、对齐等格式工作，一键导出为 PDF、DOCX、PNG 等格式。

## 1.3 目标用户

| 用户群体 | 核心诉求 |
|----------|----------|
| 求职者（主要） | 快速制作专业简历，不想花时间排版 |
| 应届毕业生 | 免费、易用、模板美观 |
| 频繁跳槽者 | 多版本简历管理，快速更新 |
| 简历模板设计师 | 开发模板供他人使用 |

## 1.5 非目标（明确不做）

- **在线协作**：本应用是单机桌面应用，不支持多人实时协作
- **在线投递**：不集成招聘平台 API，用户自行上传导出的文件
- **移动端**：首期仅支持桌面（Windows/macOS/Linux），不考虑移动端
- **.doc 格式**：不支持导出 Word 97-2003 .doc 二进制格式，仅支持 .docx
- **AI 生成内容**：MVP 阶段不集成 AI 写作功能，后续可作为扩展

## 1.6 术语定义

| 术语 | 定义 |
|------|------|
| **模板 (Template)** | 一组预定义的 HTML/CSS 文件，定义了简历的视觉布局、配色、字体和排版规则 |
| **简历数据 (Resume Data)** | 用户填写的结构化信息（个人信息、经历、技能等），以 JSON 格式存储 |
| **项目文件 (.resume.json)** | 用户保存的简历数据文件，包含完整的简历内容和选用的模板引用 |
| **模板元信息 (Template Meta)** | 描述模板属性的 JSON 文件，包含名称、作者、版本、预览图、所需数据字段 |
| **渲染 (Render)** | 将简历数据 + 模板合并生成最终 HTML/PDF/DOCX/PNG 的过程 |
| **预览窗 (Preview Pane)** | 应用右侧/下方实时展示渲染结果的区域，所见即所得 |
| **编辑窗 (Editor Pane)** | 应用左侧/上方的结构化表单区域 |

## 1.7 技术原则

1. **内容与样式严格分离**：用户数据（JSON）与模板（HTML/CSS）完全解耦，切换模板无需重新录入
2. **模板即文件**：一个模板 = 一个文件夹，包含自描述的元信息和渲染文件，拖入即可安装
3. **离线优先**：应用完全离线工作，无需网络连接（除模板市场等在线功能）
4. **数据便携**：简历数据存储为标准 JSON 格式，用户完全拥有自己的数据
5. **Go 主导**：核心逻辑全部由 Go 实现，前端仅负责用户交互
