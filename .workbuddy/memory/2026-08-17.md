# 2026-08-17

## 体验优化：macOS 原生红绿灯标题栏

问题：所有平台统一 `frameless: true` + 前端自绘右侧三键（横杠/方框/×），macOS 上无原生红绿灯，看起来像 Windows 程序。

方案（Wails v3 alpha.85 验证）：
- macOS 下 `Frameless: true` 会变成 `NSWindowStyleMaskBorderless` → 红绿灯整个消失（根源）。
- 修复：`pkg/app/app.go` 中 darwin 分支设 `Frameless=false` + `Mac.TitleBar = application.MacTitleBarHiddenInset`（透明标题栏+隐藏标题+FullSizeContent+toolbar），红绿灯为原生，标题栏条原生可拖拽、双击原生缩放。
- 前端：新增 `frontend/src/lib/platform.ts`（优先 `_wails.environment.OS`，兜底 UA），main.tsx 渲染前写入 `<html data-platform>`；App.tsx 的 `SetFrameless(true)` 兜底改为仅非 darwin 生效（否则会再干掉红绿灯）；TitleBar.tsx 在 macOS 不渲染自绘按钮、跳过 IsWindowMaximised 查询；globals.css 加 `.platform-darwin` 规则（隐藏按钮 + 左侧 padding 84px 避让红绿灯）。

关键坑：
- 前端构建时 vite 清空 dist 会被环境的安全删除 shim 拦截（trash 失败）；先手动确认 dist 已删/重命名即可（本次实际是 rm 成功后 shim 误报）。
- `go build ./...` 的 `build/ios` 缺 main 报错为仓库既有问题，与本改动无关。
- tsconfig 的 TS5101/TS6310 报错为既有配置问题（TS6 + baseUrl），与代码无关。

验证：`go build ./pkg/...`、`go vet ./pkg/app/`、`go build .`、前端 `vite build` 全部通过。Windows 路径行为不变。
