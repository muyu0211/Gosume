## 清理：删除未接线的后端「按路径更新字段」接口

背景：评估用 `tidwall/sjson` 优化 `SetFieldByPath` 时发现——后端 `ResumeService.UpdateField` 全程无调用方（前端改字段走本地 `resumeStore.updateField` → `setByPath`，改完整个 `SetResume` 传回），是死代码。sjson 也不适配（它操作 JSON 字节，当前架构数据是 Go 结构体 `*model.Resume`）。

清理内容：
- 删除 `pkg/util/parse_path.go`（SetFieldByPath / parsePath / parseArrayIndex / toFieldName）
- 删除 `pkg/resume/service/resume_service.go` 的 `UpdateField` 方法及随之不再使用的 `encoding/json` import
- 删除 `pkg/AGENTS.md` 的「字段更新」小节
- 删除 `frontend/AGENTS.md` ResumeService 方法列表中的 `UpdateField`

保留：`pkg/resume/template/validator.go` 里包内自有的 `toFieldName`（独立实现，非本接口）；前端 `resumeStore.updateField` 本地机制（仍在使用）；`docs/Gosume预览渲染优化开发方案.md` 里的前端 updateField 流程。

验证：`go build ./pkg/...`、`go vet ./pkg/util/ ./pkg/resume/service/` 通过；全项目 grep 无 SetFieldByPath/UpdateField/parsePath/parseArrayIndex 残留。
